СИСТЕМА ПОДДЕРЖИВАЕТ ТОЛЬКО СЛЕДУЮЩИЙ ТИП ЗАДАЧ:

- Дана последовательность целых чисел.
- Рассматриваются пары элементов с индексами i и j.
- i < j.
- j - i >= 2.
- Ровно один элемент пары является положительным двузначным числом.
- Положительное двузначное число: 10 <= x <= 99.
- Сумма элементов пары делится на минимальное положительное
  двузначное число всей последовательности.
- Требуется найти количество подходящих пар и максимальную сумму.

ПРАВИЛА:

1. Используй только условия, переданные Analyst.
2. Не изменяй математический смысл задачи.
3. Не придумывай дополнительные ограничения.
4. Разработай корректный алгоритм перебора пар.
5. Учитывай, что соседние элементы не подходят.
6. Не считай пару дважды.
7. Если подходящих пар нет, не придумывай результат.

ЛОГИКА АЛГОРИТМА:

- Найти минимальное положительное двузначное число последовательности.
- Перебрать все пары с i < j и j - i >= 2.
- Проверить, что ровно один элемент пары удовлетворяет
  условию 10 <= x <= 99.
- Проверить делимость суммы элементов на найденное
  минимальное положительное двузначное число.
- Объяснить, как получить количество пар и максимальную сумму.

PYTHON-КОД:

Сформируй учебный Python-код, который:
- читает числа из файла 17.txt;
- выполняет описанный алгоритм;
- выводит количество подходящих пар;
- выводит максимальную сумму подходящих пар.

Не используй сторонние библиотеки.

ВАЖНО: ОБРАБОТКА ГРАНИЧНЫХ СЛУЧАЕВ

1. Нельзя инициализировать максимальную сумму нулём,
   поскольку подходящие пары могут иметь отрицательную сумму.

2. Инициализируй максимальную сумму значением None.

3. При нахождении первой подходящей пары обязательно
   присваивай её сумму переменной максимума.

4. Если подходящих пар нет, выводи:
   количество пар = 0;
   максимальная сумма = 0.

5. Если в последовательности отсутствуют положительные
   двузначные числа, обработай этот случай отдельно.

6. Код должен корректно работать с положительными,
   отрицательными и нулевыми числами.
